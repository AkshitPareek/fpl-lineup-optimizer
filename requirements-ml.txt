# FPL ML Integration - Dependencies

## System Dependencies

### PostgreSQL Client Tools
Required for database operations (backup, restore, migrations).

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install postgresql-client
```

**macOS:**
```bash
brew install libpq
brew link libpq --force
```

**Windows:**
Download PostgreSQL installer from https://www.postgresql.org/download/windows/
Select "Command Line Tools" during installation.

Verify installation:
```bash
psql --version
pg_dump --version
```

## Docker Setup (Alternative)

If using Docker, the PostgreSQL client tools are included in the base image:

```dockerfile
FROM python:3.11-slim

# Install system dependencies
RUN apt-get update && apt-get install -y \
    postgresql-client \
    gcc \
    && rm -rf /var/lib/apt/lists/*

# Install Python dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application
COPY . /app
WORKDIR /app
```

## Troubleshooting

**"psql: command not found"**
- Install PostgreSQL client tools (see above)
- Ensure PostgreSQL client binaries are in PATH

**"No module named 'xgboost'"**
- XGBoost requires C++ compiler. On Ubuntu: `sudo apt-get install build-essential`
- Or use pre-built: `pip install xgboost --no-binary xgboost`

**"TensorFlow import errors"**
- If no GPU, install tensorflow-cpu instead: `pip install tensorflow-cpu`
- Or use lighter alternative: `pip install jax` and adjust code

**"psycopg2-binary installation fails"**
- Install system dependencies first:
  - Ubuntu: `sudo apt-get install libpq-dev python3-dev`
  - macOS: `brew install postgresql`
  - Then: `pip install psycopg2-binary`
